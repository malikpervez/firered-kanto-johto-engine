Clover Glade
Soft clover clusters, fine undergrowth and gentle mottled light.

Four detailed 16x16 lawns plus a daisy tile. All five mix in any order
horizontally and vertically. Each option is a separate colour/texture set.
Each option keeps its original six greens and all nine soil/prop colours.
Grass uses only its six greens, with rare soil-light flecks in Spring Meadow.
Daisies use cream petals and soil-light centers. All pixels are opaque.

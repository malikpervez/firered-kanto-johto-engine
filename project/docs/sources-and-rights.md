## Credits and notices

It also marks the crediting policy and HnS-specific credits refresh as TODO. Keep the original notices in ignored source checkouts and reference the complete [pinned CREDITS.md](https://github.com/PokemonHnS-Development/pokehns-expansion/blob/167aa6d537b109bb229c231ddce4616974c4da71/CREDITS.md); do not replace the contributor list with only the project name.

That credits file contains the all-contributors list and names princess-phoenix, larryturbo and kidkatt for Mega Evolution overworld sprites. Those links are attribution leads, not established permissions for every asset. The HnS player-documentation credits link is a moving supplemental source and has not been substituted for the pinned notices.

`git ls-files '*LICENSE*' '*COPYING*' '*NOTICE*'` found **no repository-wide license file** at this pin. It found eight MIT-style tool licenses: `tools/bin2c`, `gbagfx`, `mid2agb`, `preproc`, `ramscrgen`, `rsfont`, `scaninc`, and `wav2agb`. The first seven name YamaArashi (2015/2016); wav2agb names ipatix (2016). These notices require retention when applicable material is copied. [Example pinned MIT notice](https://github.com/PokemonHnS-Development/pokehns-expansion/blob/167aa6d537b109bb229c231ddce4616974c4da71/tools/gbagfx/LICENSE). The embedded json11 source also carries an MIT-style notice; preserve it if reused.

One material notice mismatch is unresolved: [`tools/gbafix/COPYING`](https://github.com/PokemonHnS-Development/pokehns-expansion/blob/167aa6d537b109bb229c231ddce4616974c4da71/tools/gbafix/COPYING) contains GPL version 3, while [`gbafix.c`](https://github.com/PokemonHnS-Development/pokehns-expansion/blob/167aa6d537b109bb229c231ddce4616974c4da71/tools/gbafix/gbafix.c#L1) declares GNU Library GPL version 2 or later.
